EDM92 — Car & Truck Physics

A real-time vehicle dynamics simulation for cars and trucks built in Unity. The project models how a vehicle actually behaves on the road — suspension travel and load transfer, tyre grip, drivetrain and engine torque delivery — so that light passenger cars and heavy trucks each handle with their own distinct, believable character.

Car Part Search

A meta-search tool for car parts in Romania. Enter a part code once and it builds the search URLs for more than 35 Romanian online parts stores, so prices and availability can be compared in one place. You can open each store's results individually or all at once. It is a standalone Angular application deployed on Vercel.

Thermostat

A full-stack smart thermostat for combi boilers running on a Raspberry Pi 4. A Spring Boot service reads a DHT11 temperature sensor and drives a relay over GPIO, pulls outdoor conditions from the OpenWeatherMap API, optionally logs readings to AWS DynamoDB, and pushes live data over WebSockets to an Angular control panel served behind an Apache reverse proxy.

  • Java
  • Spring Boot
  • Angular
  • TypeScript
  • Raspberry Pi
  • GPIO
  • WebSockets
  • AWS DynamoDB
